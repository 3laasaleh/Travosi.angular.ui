1. What the platform is

A complete, production-ready travel website built on Angular 22 with server-side rendering. Every public page is rendered on the server before it reaches the browser, so Google, Bing and social networks see the full content instantly — this is the single biggest difference between this platform and an ordinary single-page website.

The site runs fully in English and Arabic, on separate, indexable URLs (/en/tours and /ar/tours), with automatic right-to-left layout for Arabic. Prices are shown in EGP or USD using a live exchange rate.

2. Catalogue & content modules

2.1 Destinations

  • Paginated destinations index; each card carries its own image carousel.
  • Destination detail page: full photo gallery with a full-screen lightbox viewer, bilingual description, the cities that belong to the destination, and a carousel of tours available there.
  • Clean, human-readable URLs driven by a slug, e.g. /en/destinations/hurghada.

2.2 Cities

  • Shows the top tours inside the city plus recommended tours from the wider destination, so the visitor always has something to click.

4. Search engine optimisation (SEO)

SEO is not an add-on here; it is engineered into the framework. A single service governs every page's search presence, so nothing is ever forgotten on a new page.

Server-side renderingEvery public page is rendered on the server, so crawlers receive complete HTML — not an empty shell.
Titles & meta descriptionsGenerated per page and per language from the actual content of the tour, package, destination or article.

hreflang alternatesEnglish and Arabic versions are formally linked, so Google serves the right language to the right user.

BreadcrumbsVisible breadcrumb trail on every page, localised, and published as breadcrumb structured data.

5. Technical foundation

  • Angular 22, standalone components, signals.
  • Server-side rendering + hydration with an HTTP transfer cache (no duplicate API calls on load).
  • Lazy-loaded routes — the browser downloads only what the page needs.
  • OnPush change detection throughout for fast rendering.
  • Tailwind CSS, fully responsive from mobile to desktop.
  • Full RTL support for Arabic.
  • JWT authentication with route guards.
  • Live currency conversion (EGP / USD) with caching and fallback.
  • Built-in visitor tracking for on-site statistics.
