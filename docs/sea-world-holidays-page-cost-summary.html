1. Pricing model

Every page of the system is priced as a unit of delivery. A page includes its layout, data loading, English and Arabic content, RTL handling, loading and error states, responsive behaviour and QA.

The blended engineering rate is EGP 1,000 per hour (about USD 21), so a 5,000 EGP page is five hours of work and an 8,000 EGP page is eight.

2. What the system does

Sea World Holidays is a bilingual travel platform with three audiences on one codebase:

  • Visitors browse destinations, cities, tours, Nile cruises, packages and travel articles, then request a booking.
  • Customers sign in to track their bookings, invoices and profile, and to review completed trips.
  • Staff (Admin / Agent) manage the whole catalogue, the booking queue and the financial documents from a back office.

Every public page is server-rendered for search engines, carries structured data and breadcrumbs, and is available on both /en/… and /ar/… with automatic right-to-left layout.

5. What is included in every page price

  • Layout and responsive implementation from the agreed design
  • Integration with the backend API, including loading, empty and error states
  • English and Arabic content wiring with right-to-left layout verification
  • Server-side rendering compatibility, page metadata, structured data and breadcrumbs (public pages)
  • Access control and search-engine exclusion (account and back-office pages)
  • Manual QA on desktop and mobile, code review and one round of revisions

6. Not included

  • Backend / API development and database work
  • Online payment gateway integration — the booking flow captures requests, it does not take card payments
  • Hosting, domains, SSL and infrastructure
  • Original UI/UX design, photography, copywriting and translation
  • Content entry for destinations, tours, packages and articles
  • Automated test suites and ongoing maintenance or support retainer
Scope control. The price is fixed per page. Adding a page adds 5,000 EGP (8,000 EGP for a tour page). Reworking a page after it has been signed off is quoted separately.
